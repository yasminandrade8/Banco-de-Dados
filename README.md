## 📌 Sobre o Repositório

Este repositório reúne as atividades práticas da disciplina de Banco de Dados Relacional. O foco do conteúdo inclui desde a criação da estrutura das tabelas até a construção de consultas complexas, visões e automações no SGBD.

## 🛠️ Ferramentas & SGBD Utilizados

* **SGBD:** MySQL (v8.0+)
* **Interface / Ferramenta Client:** MySQL Workbench / DBeaver / VS Code (SQL Tools)
* **Linguagem:** SQL (Structured Query Language)

## 💻 Como Rodar os Scripts

1. Clone o repositório:
   ```bash
   git clone [https://github.com/yasminandrade8/Banco-de-Dados.git](https://github.com/yasminandrade8/Banco-de-Dados.git)

2. Abra seu gerenciador MySQL de preferência (ex: MySQL Workbench ou DBeaver).

3. Conecte-se ao seu servidor local.

4. Execute o arquivo .sql desejado para criar as tabelas e povoar a base de dados.
